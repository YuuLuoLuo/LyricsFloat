# 歌词板

> 一个常驻 Windows 桌面的**桌面歌词**小工具。

透明、无边框、始终置顶，不想要的时候鼠标穿透就完事。歌词跟着系统里正在播放的歌实时滚动，
鼠标移过去时才淡淡显形，不打扰看壁纸、写文档、打游戏。

项目名 `lyric-board`（歌词板）只是它的一种用法——它本质上是「桌面歌词」，后面可能会换成更贴切的名字。

## 特性

- **常驻桌面、鼠标穿透**：锁定时完全隐形，点击/滚轮全部穿透到下层窗口，不挡任何操作。
- **悬停显形**：鼠标靠近时磨砂玻璃背景淡入，移开淡出。
- **歌词自动匹配**：读取系统播放信息，自动从网易云音乐 / QQ 音乐 / lrclib 拉取歌词，结果本地缓存。
- **歌词旋转**：以对齐边为圆心，上下句按距离倾斜、模糊、层叠，像唱片指针一样环绕当前句。
- **歌词翻译**：当前句下方挂译文行，双语显示。
- **逐字高亮**：有时间轴的字幕逐字点亮，卡拉 OK 效果。
- **歌词信息**：显示专辑封面（左/右/不显示）与曲目标题（顶部/底部/不显示）。
- **任意组合**：以上四项是独立开关，可以同时开，排布会自动兼容。
- **自动适配**：字号过大或句子太长时自动缩字，行数随窗口高度变化，对齐方式保持一致。
- **可调外观**：字体、字号、字重、行距、水平/垂直对齐、颜色模板、当前行/其余行配色、
  描边与阴影、当前行放大、模糊强度、淡出速度、背景不透明度与色调。
- **顺手的入口**：托盘单击锁定/解锁，双击打开设置；右键菜单；开机自启；总在最前。
- **配置可带走**：设置导出到桌面 / 拖入文件导入，配置始终跟着软件本体。

## 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809（build 17763）及以上，推荐 Windows 11 |
| 架构 | x64 |
| 运行时 | WebView2 Runtime（Windows 11 自带；Windows 10 若未装，安装包/首次启动会提示） |
| 显示 | 支持任意缩放比例（100%~200% 已适配） |

> 暂不支持 macOS / Linux：歌词读取、窗口穿透、圆角裁剪走的都是 Win32 / SMTC 接口。

## 下载与安装

1. 到 [Releases](https://github.com/) 下载最新版 `lyric-board_<版本号>.exe`（例如 `lyric-board_26.11_2.exe`）。
2. 放到任意目录双击运行即可，**绿色免安装**，不写注册表（只有开启「开机自动启动」时写一条自启项）。
3. 首次运行会在 `%APPDATA%\com.yuluo.lyricboard\` 生成配置与歌词缓存，卸载时删除该目录即可。

> 如果你的电脑没装 WebView2，先装
> [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 使用说明

- **播放**：随便用哪个播放器放歌，词板会自动认出来。没有播放器时会显示「等待播放器」。
- **显形**：鼠标移到词板区域附近，背景与歌词显现；移开自动淡出。开着「锁定词板」时完全不响应。
- **锁定 / 解锁**：托盘图标**单击**切换；也可以在托盘右键菜单或设置页里切换。
- **打开设置**：托盘图标**双击**，或在词板显形时点右上角按钮 / 右键菜单。
- **拖动**：解开锁定后按住词板直接拖，位置自动记住。
- **调尺寸**：设置页拖宽/高滑块时，词板会临时显形并显示悬停背景，松手恢复原状，方便对齐。
- **本地歌词**：把 `.lrc` 文件直接拖进设置窗即可用；也支持带时间轴的逐字歌词。
- **时间对不上**：设置页「时间偏移」整体平移歌词，范围 ±3000 ms。

## 支持哪些播放器

歌词板读取的是 Windows 的**系统媒体控件（SMTC）**，也就是你按键盘媒体键、任务栏弹出的那个
「正在播放」信息。**凡是想响应媒体键的播放器，基本都能被读到**。

- **一般直接可用**：网易云音乐、QQ 音乐、酷狗音乐、Spotify、Apple Music（Windows 版）、
  MusicBee、Windows Media Player。
- **需要在播放器里开一下媒体键/系统集成**：foobar2000（组件）、PotPlayer、AIMP、JRiver。
- **网页播放**：Chrome / Edge 里播 YouTube、Bilibili、网易云网页版等，也会上报媒体会话。
- **读不到的情况**：播放器本身不实现 SMTC（部分老版本、绿色精简版），或者被系统关了媒体键支持。

## 设置项一览

设置窗分三个标签页：

**常规** — 当前播放信息（曲目 / 歌词状态 / 进度 / 时钟）、时间偏移、开机自动启动、总在最前、
锁定词板、设置文件位置与导出 / 导入 / 恢复默认、退出。

**外观** — 歌词样式（歌词旋转 / 歌词翻译 / 逐字高亮 / 显示歌词信息，含歌词信息布局）、
词板尺寸（宽 / 高 / 当前可显示几行）、字体（字体 / 字号 / 字重 / 行距）、对齐（水平 / 垂直）、
颜色（模板 / 当前行 / 其余行 / 逐字高亮）、描边与阴影、动效（当前行放大 / 模糊强度 / 淡出速度）、
背景样式（不透明度 / 色调）。

**关于** — 当前版本、检查更新、仓库与作者信息、数据目录说明。

## 从源码构建

需要：**Node.js 18+**、**Rust 1.77+**、**Visual Studio 2022 生成工具（含 C++ 与 Windows SDK）**、
Tauri 2 依赖（首次 `npm install` 自动装）。

```bash
npm install                 # 装前端依赖

# 开发调试（两个终端）
npm run dev                 # Vite 开发服务器 127.0.0.1:1420
cargo run --manifest-path src-tauri/Cargo.toml

# 发布构建
bash scripts/pack.sh        # 产物：release/lyric-board_<版本号>.exe
```

`scripts/pack.sh` 会依次做前端构建、Rust release 构建并复制成带版本号的文件名。
Windows 下如果 cargo 找不到 MSVC 环境，先 `source scripts/msvc-env.sh`。

### 版本号规则

版本号格式为 **`年份后两位.月份_当月第几次编译`**，例如 `26.11_2` 表示 2026 年 11 月第 2 次编译。

- 软件内「关于」页显示的、GitHub Release 的 tag、下载到的文件名都是这个字符串。
- exe 的**文件属性**里受资源格式限制只能填数字与点号，因此显示为 `26.11.2`（同一版本，语义一致）。
- 检查更新时按这三段数字从前往后比较，tag 带不带 `v` 前缀都认。

## 常见问题

**词板不见了？**
可能处于锁定状态（托盘单击可解锁），或者鼠标没移到它附近。位置跑出屏幕的话，
在设置页把宽度/高度动一下会把它拉回可见区域。

**歌词对不上 / 慢半句？**
先用「时间偏移」微调；如果是很多歌都偏，可能是播放器上报的进度有延迟，可以反馈具体播放器版本。

**封面显示不出来？**
封面来自播放器上报的缩略图，部分播放器（或本地无封面文件时）不提供，此时会退化成一格占位。

**杀毒软件报毒？**
未签名的自编译 exe 常见误报。可以用源码自行构建，或加入白名单。
