# LyricsFloat

> 一个面向 Windows 桌面的**桌面歌词**小工具。

透明、无边框、始终置顶，鼠标穿透。歌词跟着系统里正在播放的歌实时滚动，

![平台](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D7)
![许可](https://img.shields.io/badge/license-MIT-green)

## 特性

- **常驻桌面、鼠标穿透**：锁定时完全隐形，点击/滚轮全部穿透到下层窗口，不挡任何操作。
- **悬停显形**：非锁定状态下鼠标靠近时磨砂玻璃背景淡入，移开淡出。
- **歌词自动匹配**：读取系统播放信息，自动从网易云音乐 / QQ 音乐 / lrclib 拉取歌词，结果本地缓存。
- **歌词旋转**：以对齐边为圆心，上下句按距离倾斜、模糊、层叠，像唱片指针一样环绕当前句。
- **歌词翻译**：当前句下方挂译文行，双语显示。
- **逐字高亮**：有时间轴的字幕逐字点亮。
- **歌词信息**：显示专辑封面与曲目标题，可自定义位置。
- **自动字号**：字号过大或句子太长时自动缩字，行数随窗口高度变化，对齐方式保持一致。
- **可调外观**：字体、字号、字重、行距、水平/垂直对齐、颜色模板、当前行/其余行配色、
  描边与阴影、当前行放大、模糊强度、淡出速度、背景不透明度与色调。
- **无播放时关闭词板**：可选项。开启后没有播放、或当前媒体没有歌词时，词板整个窗口收起，一点不占；
  此时尺寸与背景设置会灰掉（字体、字号等预览能看到的项照旧可调）。
- **日志与崩溃报告**：运行日志同时写一份镜像到应用数据目录，正常退出会清掉；
  如果上次是异常退出，下次启动会问你要不要导出上次的日志（可以取消）。
  平时也可以在设置页点「导出日志」手动导出一份给反馈用。
- **可指定歌词来源**：同时开着多个播放器时，可以只认其中一个（按系统上报的播放器名选择），
  默认「自动」= 谁在播就用谁；还可以「锁定」它 —— 锁上之后即使它退出了也不会改读别的播放器。
- **托盘操作**：托盘单击锁定/解锁，双击打开设置。
- **配置可备份**：设置导出到桌面 / 拖入文件导入。

## 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809（build 17763）及以上，推荐 Windows 11 |
| 架构 | x64 |
| 运行时 | WebView2 Runtime（Windows 11 自带；Windows 10 若未装，安装包/首次启动会提示） |
| 显示 | 支持任意缩放比例（100%~200% 已适配） |

> 暂不支持 macOS / Linux。

## 下载与安装

1. 到 [Releases](https://github.com/YuuLuoLuo/LyricsFloat/releases) 下载最新版 `LyricsFloat_<版本号>.exe`（例如 `LyricsFloat_26.11_6.exe`）。
2. 放到任意目录双击运行即可，**绿色免安装**，不写注册表（只有开启「开机自动启动」时写一条自启项）。
3. 首次运行会在 `%APPDATA%\com.yuluo.lyricsfloat\` 生成配置与歌词缓存，卸载时删除该目录即可。

> 如果你的电脑没装 WebView2
> [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 使用说明

- **播放**：随便用哪个播放器放歌，词板会自动认出来。没有播放器时会显示「等待播放器」。
- **显形**：鼠标移到词板区域附近，背景与歌词显现；移开自动淡出。开着「锁定词板」时不响应。
- **锁定 / 解锁**：托盘图标**单击**切换；也可以在托盘右键菜单或设置页里切换。
- **打开设置**：托盘图标**双击**，或托盘右键菜单打开。
- **拖动**：解开锁定后按住词板直接拖，位置自动记住。
- **调尺寸**：设置页拖宽/高滑块时，词板会临时显形并显示悬停背景，松手恢复原状，方便对齐。
- **本地歌词**：把 `.lrc` 文件直接拖进设置窗即可用；也支持带时间轴的逐字歌词。
- **找不回词板**：设置页「常规 → 词板位置 → 移回屏幕中央」，把它挪回主屏顶部居中。
- **时间对不上**：设置页「时间偏移」整体平移歌词，范围 ±3000 ms。

## 支持的播放器

LyricsFloat 读取的是 Windows 的**系统媒体控件（SMTC）**，也就是你按键盘媒体键、任务栏弹出的那个
「正在播放」信息。**凡是想响应媒体键的播放器，基本都能被读到**。

- **一般直接可用**：网易云音乐、QQ 音乐、酷狗音乐、Spotify、Apple Music（Windows 版）等主流软件。
- **需要在播放器里开一下媒体键/系统集成**：PotPlayer、AIMP、JRiver。
- **网页播放**：Chrome / Edge 里播 YouTube、Bilibili、网易云网页版等，也会上报媒体会话。
- **读不到的情况**：播放器本身不实现 SMTC，或者被系统关了媒体键支持。
- **多个播放器同时在跑**：默认自动跟随正在播放的那个；也可以在「设置 → 歌词 → 歌词来源」里指定，
  指定后只看这个播放器，它退出后自动退回「自动」。

## 可设置项

设置窗口分四个标签页：**常规 / 歌词 / 外观 / 关于**。样式预览只在外观页显示。

**常规**

- 行为：开机自动启动、总在最前、锁定词板、无播放时关闭词板（没有播放或没有歌词时词板整个关闭）
- 词板位置：移回屏幕中央（词板被拖出屏幕外时用来找回）
- 设置文件：位置与「复制」路径、导出到桌面、导入…、恢复默认
- 日志：导出日志
- 退出 LyricsFloat

**歌词**

- 播放器：当前播放器（正在读哪个播放器）、歌词来源（自动 / 指定某个播放器）、
  锁定已选择的播放器（锁上后即使它退出也不改读别的播放器）
- 当前播放：曲目、歌词（行数与来源）、进度、时钟
- 同步：时间偏移（±3000 ms）

**外观**

- 歌词样式：歌词旋转、歌词翻译、逐字高亮、显示歌词信息（四个独立开关，可任意组合）
- 歌词信息布局：位置（顶部 / 底部）、封面（左侧 / 右侧 / 不显示）、
  文本位置（左 / 中 / 右 / 不显示）—— 仅在「显示歌词信息」打开时出现
- 词板尺寸：宽度、高度、「当前大约可显示 n 行歌词」
- 字体：字体、字号、字重、行距、文本超出时自动缩小
- 对齐：水平（左 / 中 / 右，开启歌词旋转时只留左 / 右）、垂直（顶部对齐 / 垂直居中）
- 颜色：模板（白字 / 黑字）、当前行、其余行、逐字高亮（仅逐字高亮打开时）
- 描边与阴影：描边宽度、描边颜色、阴影强度、阴影颜色
- 动效：当前行放大、模糊强度、淡出速度（后两项在开启歌词旋转时隐藏，模糊/淡出由旋转样式自带）
- 背景样式：不透明度、色调

**关于**

- 版本：当前版本、检查更新（有新版本时可直接「前往下载」跳到 GitHub Release），并显示 Release 说明
- 项目：仓库地址（可一键打开）、作者
- 使用与数据：设置只存在本机

## 从源码构建

需要：**Node.js 18+**、**Rust 1.77+**、**Visual Studio 2022 生成工具（含 C++ 与 Windows SDK）**、
Tauri 2 依赖（首次 `npm install` 自动装）。

```bash
npm install                 # 装前端依赖

# 开发调试（两个终端）
npm run dev                 # Vite 开发服务器 127.0.0.1:1420
cargo run --manifest-path src-tauri/Cargo.toml

# 发布构建
bash scripts/pack.sh        # 产物：release/LyricsFloat_<版本号>.exe
```

`scripts/pack.sh` 会依次做前端构建、Rust release 构建并复制成带版本号的文件名。
Windows 下如果 cargo 找不到 MSVC 环境，先 `source scripts/msvc-env.sh`。

## 常见问题

**词板不见了？**
可能是锁定了（托盘单击解锁），或者被拖到了屏幕外面 —— 打开设置页，常规标签页最下面点「移回屏幕中央」就能找回来。

**歌词对不上 / 慢半句？**
先用「时间偏移」微调；如果是很多歌都偏，可能是播放器上报的进度有延迟，可以检查播放器设置。

**封面显示不出来？**
封面来自播放器上报的缩略图，部分播放器（或本地无封面文件时）不提供，此时会退化成一格占位。

**杀毒软件报毒？**
未签名的自编译 exe 常见误报。可以用源码自行构建，或加入白名单。
